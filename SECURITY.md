# Bezpieczeństwo / Security

Zespół EnviroSolutions traktuje sprawy cyberbezpieczeństwa piorytetowo. Dokładamy wszelkiej starannosci, aby nasze oprogramowanie było wolne od błędów i było bezpieczne w użytkowaniu.


The EnviroSolutions team takes security seriously. We ensure that our software is error-free and safe to use.


## Raportowanie podatności na ataki / Reporting a vulnerability

WAŻNE! Jeśli znaleziono lukę w zabezpieczeniach, nie publikujemy jej poprzez narzędzie ISSUE. Prosimy, aby zgłoszenie wysłać pod adres email [email](mailto:email)

Prosimy załączyć jak najwięcej informacji o zdarzeniu takich jak:
- Opis błędu
- Krok po kroku jak luka została odkryta
- Źródło pochodzenia wadliwego oprogramowania (github, wtyczki QGIS, strona internetowa, nośnik danych, inne..)
- Wersja QGIS oraz wersja wtyczki


IMPORTANT! If you discover a security vulnerability, please do not open a public ISSUE. Please report it by emailing [email](mailto:email)

Please include the following details in your report:
- A description of the vulnerability
- Steps to reproduce the issue
- Source of the faulty software (github, QGIS plugins, website, storage medium, other..)
- QGIS version and plugin version


## Podstawowe zasady bezpieczeństwa / Security best practices

Niezależnie od wyników pracy programistów pracujących nad poprawkami, pamietaj o podstawowych zasadach cyberbezpieczeńtwa:

- Regularnie aktualizuj oprogramowanie do najnowszej wersji
- Zabezpiecz dostęp do komputera i do sieci komputerowej
- Monitoruj system pod kątem nietypowej aktywności


Regardless of the results of the developers working on the patches, remember the basic principles of cybersecurity:

- Regularly updating your software to the latest version
- Securing access to your computer and network
- Monitoring systems for unusual activity
